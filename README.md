# Utopia

A personal finance / household budget management API that is partially compatible with Firefly-III.

## Goal

To provide a lightweight, self-hostable alternative to Firefly-III while maintaining API compatibility with its ecosystem for supported features.

## Repository Structure

- `src/` - Application source code, including the API, core logic, and domain modules.
- `tests/` - Integration and behavioral tests.
- `migrations/` - Database schema migration scripts.
- `docker/` - Local and observability-related container configuration.
- `aidlc-docs/` - Architecture, planning, and implementation documentation.
- `scripts/` - Maintenance and automation scripts.
- `openapi.yaml` - API contract definition.
- `Cargo.toml` - Rust package metadata and dependency configuration.
